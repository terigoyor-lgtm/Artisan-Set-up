ARTISAN SETUP — ROASTING TEGUH 60 KG

CARA MEMBUKA DI WINDOWS
1. Ekstrak file ZIP ini ke folder yang mudah ditemukan.
2. Buka folder artisan-setup-teguh.
3. Klik dua kali index.html. File akan terbuka di Chrome.
4. Tidak perlu XAMPP, database, atau instalasi package.

FITUR
- Panduan persiapan adaptor USB-RS485.
- Langkah setup Artisan Scope.
- Checklist progress.
- Form hasil uji COM, suhu, dan lampu TXD/RXD.
- Ringkasan hasil yang dapat disalin.
- Troubleshooting suhu belum terbaca.

PENTING
Konfigurasi komunikasi HYUNYOUNG VX4 / UMMA-A1C belum terkonfirmasi. COM5 menunjukkan adaptor terdeteksi, bukan bukti protokol sudah cocok. Jangan menebak baud rate/parity/protokol. Minta manual komunikasi kepada pemasok/pabrikan.

Website ini adalah panduan; tidak terhubung langsung ke mesin dan tidak mengontrol mesin roasting.
